# Blogger 必須ページの設置手順(AdSense審査対策)

このフォルダの3ページを、Bloggerに「固定ページ」として作成してください。AdSense審査に必要です。

## 設置するページ

| ファイル | Bloggerでのページタイトル |
|---|---|
| 01_プライバシーポリシー.html | プライバシーポリシー |
| 02_お問い合わせ.html | お問い合わせ |
| 03_運営者情報.html | 運営者情報 |

## 手順(1ページあたり2分)

1. Bloggerの管理画面 左メニュー →「**ページ**」→「**新しいページ**」
2. タイトルに上記のページ名を入力
3. 本文エリア右上の鉛筆アイコンから「**HTMLビュー**」に切り替える
4. 対応する `.html` ファイルの中身を全部コピーして貼り付ける
5. 右上「**公開**」

3ページとも公開したら、メニュー(フッターやサイドバー)にこの3ページへのリンクを表示させると、審査で見つけてもらいやすくなります(Bloggerの「レイアウト」→「ページ」ガジェットを追加)。

## ⚠️ 各ページで必ず直すところ

- **お問い合わせ**: Googleフォームを作って埋め込んでください
  1. https://forms.google.com/ で「お名前・メール・お問い合わせ内容」のフォームを作成
  2. フォーム右上「送信」→ `< >`(埋め込み)アイコン → HTMLをコピー
  3. `02_お問い合わせ.html` の `【お問い合わせフォームをここに設置】` の部分と置き換えて貼り付け
- **運営者情報**: 運営者名を「Interkyky」にしています。別のペンネームにしたい場合は書き換えてください
- **プライバシーポリシー**: そのまま使えます(Googleアナリティクスを使わない場合は該当section削除でも可)

これで審査の必須要件(プライバシーポリシー・問い合わせ・運営者情報)が揃います。
